# STACK-Team-Brain
Team brain for i'm stacking it. Any AI (Claude, Gemini, ChatGPT) can read it and add to it.

## Files
- `CONTEXT.md` is the source of truth: product, decisions, deadlines, who does what.
- `dropdowns /from <name>/` is each person's folder for updates and files.

## Give your AI the context
Open `CONTEXT.md`, click **Raw**, copy everything, paste it into your AI chat, then ask your question.

## Post your update (no coding needed)
1. Ask your AI: *"Write my STACK update for today in short markdown: what I did, what's next, any blockers."*
2. Open your folder in `dropdowns /from <name>/`, then **Add file → Create new file**.
3. Name it with today's date, like `2026-11-27.md`, paste the AI's text, and click **Commit changes**.

Other files (screenshots, outputs): open your folder, then **Add file → Upload files**.

## Update the context
If a decision changes, edit `CONTEXT.md` (pencil icon), or have your AI rewrite it and paste the new version back.
